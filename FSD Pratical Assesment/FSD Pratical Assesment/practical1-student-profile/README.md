# Practical 1: Student Profile (React Components & Props)

## Structure
```
practical1-student-profile/
├── index.html
├── package.json
├── vite.config.js
└── src/
    ├── main.jsx
    ├── App.jsx
    ├── index.css
    └── components/
        └── Student.jsx
```

## What it demonstrates
- `Student.jsx` — a functional component that receives `name`, `course`, and `college` as **props** and displays them with JSX.
- `App.jsx` — renders **three** `Student` components with different prop values.

## Run it
```bash
npm install
npm run dev
```
Open the printed local URL (usually `http://localhost:5173`).
